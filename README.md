# 快填助手

快填助手是一个本地运行的 Chrome 扩展，用于读取用户导入的简历信息，并辅助填写招聘网站中的常见表单字段。

## 功能

- 支持导入 XLSX、CSV、PDF、DOCX 简历资料。
- 在当前网页内扫描可填写控件，并提供预览与一键填写。
- 使用字段上下文识别核心字段：姓名、手机号、邮箱、学校、专业、学历、公司、职位、期望城市、期望薪资。
- 根据 `label`、`placeholder`、`aria-label`、`name`、`id`、附近文字和表单区域标题综合识别字段。
- 遇到学校/公司冲突、紧急联系人电话等不明确场景时返回未知字段，不猜测填写。
- 资料仅保存于浏览器本地存储；扩展不需要网络权限。

## 安装

1. 下载或克隆本仓库。
2. 在 Chrome 地址栏打开 `chrome://extensions`。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择本仓库根目录（包含 `manifest.json` 的目录）。
6. 在任意招聘网页点击浏览器工具栏中的“快填助手”图标。

每次拉取新版本后，在扩展管理页点击“重新加载”即可生效。

## 使用方法

1. 打开招聘网站的简历或申请表页面。
2. 点击工具栏中的扩展图标，打开页面内的快填面板。
3. 导入本地简历文件，或选择已保存的简历版本。
4. 先使用“扫描当前页面”或“预览识别结果”检查字段映射。
5. 确认后点击“一键填写当前页面”。
6. 对下拉框、级联选择器、日期选择器、上传文件和未识别字段进行人工确认。

快填助手不会提交表单，也不会绕过验证码、登录或网站权限。

## 开发与验证

项目没有构建步骤，Chrome 直接加载源文件。

```powershell
node .\tests\field-context.test.js
node .\tests\lifecycle-regression.test.js
```

字段上下文测试覆盖十个核心字段，以及学校/公司、普通联系电话/紧急联系人电话冲突场景。

## 隐私

- 简历资料存放在浏览器本地存储中。
- 扩展不包含远程服务、分析 SDK 或上传逻辑。
- 用户应在填写前核对识别结果，并自行决定是否提交目标网站表单。
